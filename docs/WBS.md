## 任务编码规则

**ID 格式：** `{F}-{N}`

- `{F}` = 功能模块号（F-01 ~ F-11）
- `{N}` = 模块内任务序号

**验证状态：**

| 标记 | 含义 |
|------|------|
| ✅ 已有待测 | 功能代码存在，需 E2E 验证 |
| 🔴 缺失待开发 | 代码不存在，需新开发 |
| 🟡 待修复 | 代码存在但不完整/有BUG |
| 🔵 待测试 | 开发完成，等小Q E2E |
| ✅ E2E通过 | 三层联动验证通过 |
